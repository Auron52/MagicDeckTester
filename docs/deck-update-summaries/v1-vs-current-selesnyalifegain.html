A goldfish win on turn 6 or later (≥T6, including non-wins) is too slow against a fast deck.

  • Over half of standard games now end by turn 4, up from fewer than one in five. Neither list ever wins before turn 4 (0 of 160,000 games).
  • Almost all of the speed is the cards. With both lists on v1's keep table and value sidecar, the screen measured −0.5086t standard and −0.5330t 2HG.
  • Most of the cost drop is not the cards. The new list plays leafless at depth 6 where v1 used a learned value table at depth 5; the card changes alone cut cost to about 0.7×.
  • Goldfish measures speed only. The lifegain package stays (more Feed the Clan, Heroes' Reunion, more Blighted Steppe) and now feeds Bogbeast's damage.

Method. 160,000 games (40,000 per list per format), each list at its own shipped setting (v1 d5, current d6; 20 ms), max_turns 8. 2HG = 30 life, 2 opponent heads. 10 paired blocks per list: both lists see the same shuffles. Each list plays with its own shipped profile, keep table and value sidecar.
