# Cast-order rankings, per deck

**These are a PROPOSAL for user review** (see the review rule in
docs/design/cast-order-ideal-with-ranges.md): order, range and 1st-vs-2nd main are a per-deck
judgement the user signs off. Generated by `mtg <deck> --cast-order-report` with
`MTG_IDEAL_ORDER=1`, straight from each deck's real provider, so the table cannot drift from play.

## How to read it

`rank` = where it is cast today (lower = earlier). `range` = `[ideal..cost-efficient]`, shown only
where they differ. `main` = the baseline m1/m2/both classification. A `-` range means the card is
already at its ideal position.

**Draws.** Drawing is not enough to earn the information tier (rank 2): Magma Opus (8), Apex of
Power (10) and Throes of Chaos (4) all draw, but each IS the turn. A draw takes rank 2 only when
casting it first leaves the turn's mana intact (mv <= `MTG_IDEAL_CANTRIP_MV`, 2). The rest keep
their cost-efficient rank and carry `[2..N]`, so the ladder can still walk them early.

**Spectacle is flagged, not solved** -- its cheap mode needs a prior damage spell, so its position
is conditional. See the worked example in the design doc.
