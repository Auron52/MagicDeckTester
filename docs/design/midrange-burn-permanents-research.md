## Implemented policy disclosure

`DecisionProvider::SpellCastEmblemTarget` owns a one-option opponent-face prune for Chandra's emblem. This exact Midrange Burn list has no own-damage or own-death payoff and no payoff for killing opponent creatures; the opponent is passive, while living opponent bodies can enable Searing Blaze. Five to the opponent also maximizes Incinerator's same-turn discount. The human chooser offers every any-target recipient. Another deck adding a damage/death payoff must override this hook or implement a full cast-trigger target axis before inheriting this policy. This is the one new autonomous target prune; it is provider-owned and must be disclosed in Stage 6a.

Paid exile casting reuses the full normal cast pipeline in each world, with a content-serialized spell action in the loyalty action's tutor_target. There is no encounter-order intern index. Lavamancer similarly stores the sorted pair of fuel names in tutor_target; changed prior worker history cannot renumber choices. The paid_cast protocol flag changes the reused free_cast dialog's wording to state the actual cost and permanent-exile disposition.
