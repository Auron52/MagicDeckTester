Source `c2c6d4a03a5c1df9cf72c55bd29940aacff41efc`; exact upstream source `520d6ef09669321b0ab80c3252a15f487a7db01c`.

`normal-evidence.tar.gz` preserves the closed normal smoke/regression reviews,72 exact source-control games,3 FiveColour recovery games, compiler parity, raw diagnostics and accepted-GT diff checks. The index binds each uncompressed file and the archive. Compiled binaries and active native-Claude conversations are excluded. These are simulator diagnostic traces, not saved hand-played reference files.

Normal initial mismatches were reviewed and promoted with explicit notes; this is not a claim that the initial harness exits were zero or that every FD was fixed. See `docs/design/cyclone-completion-review.md`. Final memory/Claude/cost gates have their own later receipts.
