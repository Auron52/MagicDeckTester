## Why d5 b20 misses the T5 line (from the USER's T4 board)
T4 decision, hand Guild Summit, Sylvan Scrying x2, The Black Gate; Exploration + Burgeoning out.
- `MTG_TRACE=search`: b20 = `T4 pass=1 done win=6 cost=5103 used=5103`, and no pass 2. b100 = the same pass 1,
  then `pass=2 done win=5 cost=735`.
- **The decision is NOT out of units.** Budget = 18,000 units and pass 1 used 5,103. FullSearchLine's ladder
  START GATE refuses pass 2. With one completed pass, the estimate is c1 x kDefaultGrowth = 5,103 x 6.0 =
  30,618. That exceeds kStartGateAlpha x remaining = 1.1 x 12,897 = 14,187. (No value sidecar, so gate_alpha
  is 1.1.) The pass it refuses really costs **735** units (0.14x pass 1, because pass 1's memos are warm).
- The arithmetic predicts the threshold: B >= c1 (1 + 6/1.1) = 32,938 units, about b36.6. Measured: b36 gives
  T6 and b37 gives T5 (pass 2 runs). Confirmed exactly.
- The two lines differ in T4 sequencing. b20 commits pass 1's greedy-tail pick: The Black Gate first (it
  enters before Guild Summit, so it draws nothing), then Summit, Scrying, Scrying, Maze's End. b100's pass 2
  finds: Summit, Scrying -> Maze's End, Maze's End, then The Black Gate, which draws off Summit. It also
  holds the second Scrying for T5.

## What a sound fold can and cannot buy here
To admit pass 2 at b20, pass 1 must satisfy 6 c1 <= 1.1 (18,000 - c1), i.e. **c1 <= 2,789 (-45%)**.
- A Summit-twin identity fold, whether it declines the apply before the copy (EtbcFold's shape) or re-prices a
  post-apply duplicate to 0 units (FB_HOLD_FOLD_FREE's shape), removes at most the duplicates' ~1 unit each:
  about 671 units, to c1 of about 4,430 (threshold about b32). Worth doing as a collapse in its own right.
  It is NOT enough for s3 at b20: the post-apply dedup already skips the duplicates' rollouts, so their
  remaining cost is only the apply unit. (EtbcFold as built keeps the unit charge, "NOT a re-price", so a
  copy of it would save wall but 0 units.)
- The other ~4.4K units are 625 DISTINCT candidates and their rollouts: Scrying target x Summit count x land
  order. Cutting 45% of distinct states is a heuristic narrowing (USER decision, default OFF), not a fold.
- The binding term is the ladder's pass-2 BOOTSTRAP estimate (6.0x), which is 42x the real warm cost here
  (735). A better pass-2 estimate is the allowed "re-price/order, inert at b0" shape: at an unlimited budget
  the gate always admits. But the gate is engine-wide (FullSearchLine and P18 / FIT / escalation all read
  kDefaultGrowth), so every deck moves and it needs an all-deck held-out A/B. Not built.
